# Skull Fortress

Skull Fortress is a Minecraft plugin designed to create a massive, evil skull fortress in Bedrock Edition. This plugin allows you to build a gigantic skull entrance, a heavily defended fortress, a lava moat, unbreakable defenses, skeleton guards, and a fully walkable interior. The fortress includes a throne room, royal bedroom, treasure vault, armory, and prison.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Use the `/ciao` command to greet yourself.
2. Build your fortress using the provided blueprints and structures.
3. Place skeleton guards at strategic locations using the plugin's commands.
4. Customize the fortress with additional decorations and features as needed.
